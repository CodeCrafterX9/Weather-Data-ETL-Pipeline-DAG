This project builds a daily ETL pipeline using Apache Airflow to fetch weather data from the Open-Meteo API and store it in a PostgreSQL database.

**Approach:**

Extracted real-time weather data using API
Transformed required fields (temperature, windspeed, etc.)
Loaded cleaned data into Postgres
Automated workflow using Airflow DAG

**Tech Stack:**
Python, Airflow, PostgreSQL, API
